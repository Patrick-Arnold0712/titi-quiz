# 分科资料导入

在「资料库 → 导入教材或习题册」选择文件。顶部的学科就是归属学科；需要新学科时，先用「新建学科」。每次导入一份资料，换学科不会转移已上传的草稿。

1. 选择 **习题册** 或 **教材**，然后点击「识别并预览」。PDF 逐页优先使用文字层，少字页自动用 [RapidOCR](https://github.com/RapidAI/RapidOCR) 本地识别；文字层乱码或页面含文字与扫描图时可勾选「PDF 每页强制 OCR」。图片直接走 OCR。
2. 检查提取文字和样题。改字、补题型/标答后点「重新检查」。没有可用标答、选项不完整或题面未通过质量门的题不会入库。没被识别成题号的文字不会计入待修正数，所以也要对照原文件。
3. 确认入库。教材按「第…章/节」、Markdown 标题或 Word 标题样式切分；没有标题则归到资料名对应的章节。习题可以按相同章节名关联教材，也可以手填章节。关联到多个既有考点时不会猜具体考点。
4. 入库后可在「刷题」和「搜索」查看。选中「同时生成练习卷」会用本次新增题建卷；客观题按现有规则判分，主观题待人工，填空题只在刷题时对照答案、不计入练习卷。作答可进入错题本并刷新备考统计。没有历年考情的新学科按章节等权安排练习，不预测考试分值。

支持文字/扫描/混合 PDF、DOCX 正文段落、UTF-8 TXT/Markdown、PNG/JPEG/BMP/WebP。分科导入的 PDF 每份最多 256 MiB、1,000 页，其他格式仍为 30 MiB，单份提取文字最多 200 万字符。整本扫描教材可能处理较久，请保持预览页面打开。PDF 标注的是文件页号，不是印刷页码。OCR 不能可靠恢复复杂公式、图形、表格或多栏阅读顺序；当前不抽取 Word 表格，不自动解题，也不从教材自动生成习题。

### 习题示例

    # 第一章 水循环
    一、单项选择题
    1. 下列哪种变化属于水的蒸发（ ）
    A. 液体变为气体
    B. 液体变为固体
    答案：A
    解析：液态水变成水蒸气。

    二、判断题
    2. 河流会改变地表形态。
    答案：正确

也可将答案放在文末：标题「参考答案」，下面逐行写「1. A」「2. 正确」；题号须全文件唯一，否则请把答案移到对应题下。同一学科内相同文件的同类导入只会提交一次，同题型、同题干和同选项的重复题不会覆盖已有作答。不同学科可分别使用同一文件。

### 接口与部署

- 使用现有 POST /api/subjects 新建学科（name、code）。
- POST /api/material-import/preview：multipart 字段 file、subject_id、kind（textbook/workbook）、可选 force_ocr。返回 draft_id、可校对的 pages 数组、识别与质检结果；此步不写题库。
- POST /api/material-import/{draft_id}/check 和 /commit：JSON 传 pages（保留原页数）、可选 chapter、make_paper。确认时重新验证，资料、考点、题目和练习卷由同一事务写入。
- 草稿 24 小时后失效，并在后续预览时清理；确认后的原件另存于 data/uploads/materials。服务仍按单进程、可信局域网自用设计。不要把未经访问保护的写接口暴露到公网。

OCR/PDF 依赖未安装时，在项目根目录运行：

    .venv\Scripts\python.exe -m pip install -r backend/requirements-ocr.txt

RapidOCR 使用项目已有的 ONNX 适配器，不需上传资料。字体、公式和试卷结构仍需要人工核对。此入口不会清洗或重算军理数据，不用重新运行军理离线导入脚本；军理押题策略和可信教材题源继续独立。

### 自检

    .venv\Scripts\python.exe tools/selftest_material_import.py

自检使用一次性数据库，覆盖 OCR、去重、分科、原文查询、质量门、练习卷判分、错题、备考统计及取值约定。
